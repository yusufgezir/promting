Module 01

Introduction to Prompt Engineering

Discover the core principles of prompt engineering, instruction structure, and how to effectively command Generative AI models.

What is Prompt Engineering?

It is the discipline of crafting, refining, and structuring text inputs to steer Generative AI models into producing consistent, high-precision outputs.

The Four Core Pillars

Clarity: Unambiguous language.
Context: Relevant background info.
Constraints: Format & length limits.
Role: Explicit Persona assignment.

Prompt Anatomy Example

[ROLE]: You are a Senior Data Science Educator. [CONTEXT]: I am introducing Large Language Models to second-year Computer Science students. [TASK]: Explain the concept of "Tokens" in natural language processing. [CONSTRAINTS]: Use a real-world analogy. Keep it under 150 words. Output in bullet points.

Module 03

Chat Models & Conversational Roles

Master the tri-role framework: System, User, and Assistant roles in multi-turn dialogues.

System Message

Configures global instructions, persona, and strict safety boundaries for the model session.

User Message

Represents the human request, query, data payload, or prompt instructions.

Assistant Response

The generated output conditioned on the system instructions and user history context.

Module 04

Designing LLM Applications

Advanced prompting techniques: Few-Shot, Chain-of-Thought (CoT), and JSON Schema Output enforcement.

Few-Shot Learning

Providing 2-5 explicit examples in the prompt to teach the model complex patterns without fine-tuning.

Chain-of-Thought (CoT)

Instructing the model to "think step-by-step" to dramatically improve mathematical and logical reasoning.

Structured Outputs

Enforcing strict JSON or XML schema outputs for automated parsing in backend software pipelines.

Module 05

Prompts, Context & RAG Architecture

Retrieval-Augmented Generation (RAG) connects LLMs to custom knowledge bases to eliminate hallucinations.

RAG Workflow Pipeline

1. Document Ingestion

Files are chunked and converted into vector embeddings.

2. Vector Search

User query finds matching context chunks from Vector DB.

3. Augmented Prompt

Context + User Query sent to LLM for grounded answer.
