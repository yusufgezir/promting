The starting point

The central question

What makes a model's next words useful for a particular task?

“The most important discovery of the experiment was…”

The same opening can lead to a scientific report, a dramatic story, or a short summary. The words surrounding the request influence which kind of continuation is likely.

Prompt engineering means designing instructions, examples, and context so that the output serves a purpose. In an application, it also includes deciding what information to retrieve, how to structure a conversation, and how to use the result.

01 / Origins

How did we get here?

Modern assistants grew out of successive ways to represent and use context.

  1. 1940s+
    Statistical language modelsMarkov-style approaches predict text from a limited preceding context.
  2. 2014
    Sequence-to-sequence modelsAn encoder and decoder transform one sequence into another, such as a translation.
  3. 2015
    Attention in neural sequence modelsThe decoder can consult relevant parts of its input instead of relying on one compressed summary.
  4. 2017
    The TransformerAttention becomes the central mechanism for relating positions in a sequence.
  5. 2018
    GPTA transformer-based text generator is broadly pre-trained and then adapted to useful tasks.
  6. GPT-2 → 3 → 4
    More capable modelsPrompting becomes a practical way to perform tasks without training a new model for each one.

Remember: This was a move from simple prediction with limited context to much more powerful context-sensitive prediction.

02 / The bottleneck

A sentence is not a single vector

Early translation systems tried to squeeze an entire input into one fixed-size representation.

An encoder reads the source sentence and compresses it into a representation sometimes called a thought vector. A decoder then generates the translated sentence one token at a time.

Source sentence→Encoder→Compressed vector→Decoder→Translation

That can work for short input. But a paragraph may contain names, qualifications, and relationships that cannot all fit cleanly into one small summary. Important details can be lost before the decoder finishes.

Attention changes the picture

With attention, the decoder can consult multiple representations of the source words. At each output step, it gives more weight to the parts that matter for the next token.

Without attention

  • One summary carries most input information.
  • Details may disappear in long sequences.
  • The fixed-size representation creates a bottleneck.

With attention

  • The decoder consults a collection of source representations.
  • Different source words can matter at different steps.
  • Relevant context is easier to reach.

Intuition: Not every input word matters equally at every moment.

03 / The architecture

Attention becomes the architecture

The 2017 transformer uses attention to connect information between token positions, without relying on recurrent processing through a sequence.

This made training on large text collections more practical and let models represent rich relationships across text.

What does GPT mean?

GGenerativeProduces new content.
PPre-trainedLearns broadly from large datasets before adapting to particular uses.
TTransformerUses transformer layers, including attention, to process context.

GPT-style text generation is usually autoregressive: the model estimates a distribution for the next token, selects one, appends it to the sequence, and repeats.

P(tn+1 | t1, t2, …, tn)Probability of a next token given the tokens so far

That repeated operation can yield answers, explanations, code, translations, and stories because the model has learned many forms of structured text.

04 / In practice

A prompt is more than a question

Two requests can ask for the same topic while giving the model very different guidance.

05 / Beyond the prompt

From a prompt to an application

A useful model interaction often has a third participant: the application that prepares the input and handles the output.

01 · UserStarts with a problem
02 · ApplicationPrepares instructions and relevant context
03 · ModelGenerates an output
04 · ApplicationChecks, formats, or uses the output
05 · ResultReturns something useful to the user

The application may retrieve documents, keep conversation history, validate an answer, format it, or call an external tool. That makes prompt engineering closely connected to application design.

06 / Reality check

Three limitations worth remembering

Not a search engine

A model can produce plausible text without retrieving or verifying a source.

Finite context

It only processes content available within its supported context limit.

Fluency is not accuracy

A well-written answer may still contain factual or logical errors.

Choosing the right information and checking important results are part of the engineering work.

Five takeaways

  1. Modern language models grew out of a long history of sequence prediction.
  2. Attention addresses the limits of compressing input into a single fixed representation.
  3. Transformers made attention central to processing language.
  4. GPT-style models generate text by repeatedly predicting the next token.
  5. A useful prompt connects a user's goal to the kind of output the model should produce.

Check your understanding

Why was one “thought vector” problematic for a long input?

It had to compress the whole input into one fixed-size representation, so names, qualifications, and other important details could be lost.

What changes when the decoder can use attention?

At each generation step, it can consult multiple source representations and give more weight to the parts relevant to the next token.

What is missing from “Explain transformers”?

It does not identify the audience, the scope and sequence, the output format, or useful constraints.
